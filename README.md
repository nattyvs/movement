# Movement

A personal training companion: today's session chosen for you, a ten-minute lazy-day version, voice and visual cues, a realm that reveals itself as you train, a small dragon who has opinions, and rewards you actually want.

Static site, no build step. Works offline once opened. Install on iPhone: open in Safari, Share, Add to Home Screen.

Your training data lives in a separate private repo (`movement-data`) and syncs through a fine-grained GitHub token you paste into Settings. Nothing personal is stored in this repo.

Exercise demos are original animated illustrations drawn in code (`figure.js`). Display type is Bodoni Moda, self-hosted under the SIL Open Font License (`fonts/OFL-BodoniModa.txt`).
